# Байкал Интеграция — b-integration.ru

Сайт интегратора Битрикс24: поддержка коробочных порталов, ИИ сотрудники, ссылка на курсы.
Laravel + админка Filament, устроен так же, как shamanka.online.

## Что есть

- **Разделы — отдельные страницы**: главная `/`, «Поддержка» `/podderzhka/`, «ИИ сотрудники» `/ii-sotrudniki/`,
  «Написать» `/napisat/`, политика `/politika/`. «Курсы» ведут на внешний сайт (адрес меняется в админке).
- **Админка** `/admin`:
  - *Разделы и страницы* — заголовки, тексты, услуги, тариф, шаги, картинка шапки, SEO. Можно завести новую страницу,
    снять с публикации (черновик видит только вошедший админ), поменять порядок в меню.
  - *Заявки* — всё, что пришло с формы «Написать»: контакт, тема, откуда пришёл человек (поиск, соцсети, UTM-метки),
    статус и заметка. Новые заявки видны счётчиком в меню; копия уходит на почту, если на сервере настроена почта.
  - *Аналитика* — посетители, просмотры, источники, сайты и сервисы, UTM-метки, устройства, популярные страницы,
    страницы входа, нажатия (почта, телефон, мессенджеры, кнопки «Обсудить», переход на курсы), заявки по источникам.
    Боты и вошедший админ не считаются, IP не хранятся. Считается только основной домен.
  - *Настройки* — контакты, почта для заявок, реквизиты, номер Яндекс.Метрики, метатеги подтверждения для вебмастеров.
- robots.txt и sitemap.xml; тестовые домены закрыты от поисковиков.

Оформление: `public/css/site.css`, скрипт `public/js/site.js`, логотип и превью в `public/img/`.
Шапка без своей картинки рисуется SVG (`resources/views/site/partials/scene.blade.php`).

## Запуск у себя

```sh
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed      # разделы и тексты с макета
php artisan storage:link
php artisan make:filament-user  # администратор
php artisan serve
```

Тесты: `php artisan test`.

## Установка на сервер

На сервере от root:

```sh
curl -fsSL https://raw.githubusercontent.com/Timophei/b-int/main/deploy/install.sh -o /root/b-int-install.sh
bash /root/b-int-install.sh
```

Скрипт ставит сайт в `/var/www/b-integration`, добавляет свой файл nginx `/etc/nginx/sites-available/b-integration.ru`
(другие сайты не трогает) и, если DNS уже смотрит на сервер, сам выпускает сертификат Let's Encrypt и включает HTTPS.
Если DNS ещё не обновился — сайт заработает по http, а повторный запуск позже включит HTTPS.

Повторный запуск — это и есть обновление: код из `main`, миграции, кэш. `.env`, база и загруженные картинки сохраняются.
Тестовый домен: `DOMAIN=t.b-integration.ru bash /root/b-int-install.sh`.

Чтобы заявки приходили на почту, заполните `MAIL_*` в `/var/www/b-integration/.env` (например, SMTP почтового ящика)
и выполните `php artisan optimize`.
